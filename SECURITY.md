# Security policy

Please report a vulnerability privately through GitHub Security Advisories for this repository.
Do not publish secrets, credentials, private model prompts or outputs, customer data, or an exploit
against a live system in an issue or pull request.

This toolkit contains workflow instructions and optional local adapters. A skill never grants new
authority. Repository write access, subprocess execution, network access, provider invocation,
deployment, publication, and destructive actions remain subject to the host and user's explicit
permissions.

Supported security fixes target the latest released minor line. Release notes will describe any
accelerated deprecation or migration requirement without disclosing exploit details prematurely.
