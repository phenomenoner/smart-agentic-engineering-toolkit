# Primary and Authoritative Source Map

Use these as entry points. Verify current editions, status, and exact claims when they affect a decision.

- SAE J3307, System Theoretic Process Analysis Standard for All Industries: https://saemobilus.sae.org/standards/j3307_202503-system-theoretic-process-analysis-stpa-standard-industries
